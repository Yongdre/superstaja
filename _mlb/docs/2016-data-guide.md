# 2016 MLB 실제 기록 기반 압축 데이터

## 사용하기

게임에 필요한 선수 파일은 `src/data/seasons/mlb-league-data-2016.json` 하나입니다. 새 커리어는 이 데이터와 2016년이 기본값입니다. 기존 커리어는 저장 당시 데이터를 유지하며, 다음 시즌 설정에서 이 JSON을 가져와 교체할 수 있습니다. 원본 기록·감사 파일·생성 스크립트는 게임 실행에 필요하지 않습니다.

실제 30팀 × (타자 9명 + 선발 5명 + 불펜 6명) = 600명입니다. 선수 이름은 공식 API의 영문 표기를 사용했습니다. 구단명은 당시 이름인 Oakland Athletics, Cleveland Indians 등을 사용합니다.

## 대표 선수 선정

- 타자는 실제 타석 수와 수비 출장 기록을 바탕으로 C·1B·2B·3B·SS·LF·CF·RF·DH를 한 명씩 채웠습니다. 수비 포지션은 해당 팀에서 10경기 이상 맡은 자리만 배정하며 DH는 제한하지 않습니다. 타순은 압축된 타격·주루 수치로 정한 가상 타순입니다.
- 주요 선수인 게리 산체스는 적은 출장에도 포함했습니다. 이적 선수는 중복 출전하지 않도록 한 구단에만 배정합니다. 원칙적으로 시즌 기여량이 가장 큰 팀이며, 채프먼(CHC), 밀러(CLE), 멜란슨(WSH), 루크로이·벨트란(TEX), 브루스(NYM), 레딕·힐(LAD), 노바(PIT), 포머랜츠(BOS), 무어(SF), 켐프(ATL)는 시즌 후반 팀을 우선했습니다. 실제 개막전/시즌 말 로스터와 완전히 같지는 않습니다.
- 투수는 선발 출장 비중과 투구량으로 선발/불펜을 구분하고 대표 5선발, 6불펜을 선정했습니다. 불펜 중 한 명만 CP, 나머지는 RP입니다. 역할은 시즌 중 섞지 않습니다. 다르빗슈·힐 등 중요한 선발은 투구량이 적어도 포함했습니다.
- 9명 고정 모델이므로 대표 타자 모두 `games: 162`이며 별도 부상·휴식·백업 교체는 없습니다. 사용자 팀은 선택한 포지션의 대표 타자를 사용자 선수로 대체합니다.

## 타자: 백업 기록을 어떻게 합쳤나

1. 각 팀의 모든 비투수 타격 기록을 모읍니다. 해당 팀에서 뛰다 이적한 선수 기록도 포함합니다. 현대식 양 리그 DH 게임이므로 투수 타격 기록은 제외합니다.
2. 팀 전체 타석을 9개 자리로 균등 배분합니다. 대표 선수의 초과 타석과 백업 타석을 부족한 자리에 나눕니다. 가능한 경우 같은 수비 포지션을 우선합니다. 이 중간 계산에서는 타석·타수·안타·장타·볼넷·삼진·도루 관련 합계가 보존됩니다.
3. 짧은 이적 후 성적이나 백업 부진 때문에 대표 선수의 특징이 사라지지 않도록 개인의 2016년 전체 시즌 비율을 60~85%, 합산 자리 비율을 15~40% 반영합니다.
4. 팀 전체 타율과 홈런/타석 비율을 중심으로 다시 맞춘 뒤 타율은 소수 셋째 자리, 홈런은 정수로 정리합니다. 홈런 환산은 타자당 162경기 × 4.1타석을 기준으로 합니다. 모든 실제 총계가 최종 JSON까지 그대로 보존되는 것은 아닙니다.
5. 선구안은 합산 볼넷/타석 비율을 게임의 1~10 척도로 환산합니다. 주루는 개인 연간 도루 시도 빈도 75% + 합산 자리 빈도 25%를 반영합니다. 실제 도루 개수·성공률을 강제하지 않으며 기존 게임의 speed별 시도/성공률 규칙을 사용합니다.

따라서 JSON의 `.280 / 25홈런`은 그 선수가 실제로 남긴 기록이라는 뜻이 아니라, 빠진 동료들의 기여까지 담아 162경기를 맡길 때의 목표 프로필입니다. 이적 당시 부진이나 소표본은 완화되지만 없어지지는 않습니다.

## 투수: 남은 투수진의 수준 반영

모든 투수의 아웃 수·자책점·삼진·볼넷·피홈런을 사용합니다. 선발군/불펜군 각각의 팀 ERA, K/9, BB/9, HR/9를 계산합니다. 대표 선수의 개인 연간 비율을 이닝에 따라 팀 평균 쪽으로 완화하고, 대표 선수들 평균이 전체 역할군 수준을 반영하도록 중심을 조정합니다. 그래서 좋은 대표 선수만 뽑아 약한 불펜이 갑자기 강해지는 현상을 줄입니다.

이 중간 비율에서 능력치를 계산합니다. `q = (2016 MLB 전체 ERA - 압축 ERA) × 7`이며, 아래의 리그 평균도 2016년 전체 투수 기록 기준입니다.

| 능력치 | 기본 환산 |
| --- | --- |
| stuff | 72 + q + (K/9 − 리그 K/9) × 4 |
| movement | 72 + q + (리그 HR/9 − HR/9) × 8 |
| control | 72 + (리그 BB/9 − BB/9) × 8 + q × 0.2 |
| stamina·SP | 38 + (연간 이닝 ÷ 선발 경기) × 8, 범위 65~96 |
| stamina·RP/CP | 38 + (연간 이닝 ÷ 등판 경기) × 5, 범위 40~57 |

첫 세 능력치는 반올림 후 25~97로 제한합니다. ERA는 종합 투구 효과를 맞추는 보정용이며 실제 구속·구종 움직임을 측정한 수치가 아닙니다. 선발/구원 겸업 선수의 이닝을 등판별로 쪼개지는 않았으므로 체력은 근사치입니다.

등급은 stuff·movement·control 평균으로 S≥85, A≥78, B≥70, C≥60, 나머지 D입니다. 등급 자체가 능력치에 추가 효과를 주지는 않습니다. 투수 JSON에는 `statProfile`을 넣지 않아 명시한 능력치가 다른 추정식으로 덮어써지지 않도록 했습니다. `strength: 70`은 구단 설명용이며 시뮬레이션 전력을 별도로 더하지 않습니다.

## 일정·규칙과 정확도의 한계

- 선수 자료만 2016년입니다. 실제 2016년의 10팀 포스트시즌, NL 투수 타격, 정확한 당시 일정은 재현하지 않습니다.
- 기존 2026 공식 일정 스냅샷의 월일·대진에 시즌 연도를 적용합니다. 팀당 162경기이며 휴식일·더블헤더를 처리합니다. 현행 12팀 포스트시즌과 토너먼트 대진표를 유지합니다.
- 사용자 요청에 따라 정규·포스트시즌 모두 자동주자를 없앴고, 동점이면 12회·18회 이후에도 계속합니다. 끝내기/이닝 종료로 승부가 나면 종료합니다. 무승부 규칙은 없습니다. 비정상 상태에 대비한 1만 타석 실행 안전장치는 별개로 유지합니다.
- 대표 9명 고정, 투수 11명, 1~4 포스트시즌 선발 순환, 등판 역할 고정은 게임 단순화입니다. 실제 로스터·부상·휴식·이동일을 그대로 재현하지 않습니다.
- 상대 능력치, 투수 기용, 타순, 사용자 선택 및 난수 때문에 결과가 바뀝니다. 특정 개인 성적이나 팀 순위를 보장하도록 시즌 결과를 강제하지 않습니다.

## 원본과 재생성

- `docs/sources/mlb-2016-records.json`: 공식 API에서 받은 30팀의 전체 타격·투구·수비 기록 및 요청 URL.
- `docs/sources/mlb-2016-people.json`: 선택된 600명의 공식 이름과 좌/우/양타, 투구 손.
- `docs/2016-compression-audit.json`: 각 자리의 원본/합산 기록, 백업 기여, 투수 역할군 목표 비율, 최종 투수 능력치.
- `scripts/fetch-2016-records.mjs`: 공식 기록 조회용. 인터넷 연결 필요. 기본 전체 팀, 팀 ID 인자로 일부 조회 가능. JSON을 표준 출력만 하고 기존 파일을 덮어쓰지 않습니다.
- `scripts/generate-2016-data.mjs`: 보관 원본으로 재생성. 인터넷 연결 불필요. `--selection`, `--audit`, `--teams=LAD,BOS`, `--compact` 옵션을 지원하며 역시 표준 출력만 합니다.

공식 출처: [MLB 2016 팀 타격 기록](https://www.mlb.com/stats/team/runs/2016), [MLB Stats API 타격 조회 예시](https://statsapi.mlb.com/api/v1/stats?stats=season&group=hitting&season=2016&teamId=119&sportIds=1&playerPool=ALL&limit=1000). 자료 수집일은 2026-09-12입니다.
