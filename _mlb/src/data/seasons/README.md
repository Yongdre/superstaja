# MLB 연도별 리그 데이터

완전한 MLB 리그 JSON을 이 폴더에 넣으면 파일명에 관계없이 자동 등록됩니다. mlb-league-data-YYYY.json 형식을 권장합니다.

- 파일명의 첫 4자리 연도를 기준으로 등록하고 ver/version 표기를 선택 목록에서 숨깁니다. 파일명에 연도가 없다면 sourceSeason을 사용합니다. label은 데이터 이름입니다.
- 동일 연도의 여러 버전도 서로 다른 파일명으로 보관할 수 있습니다.
- 새 커리어와 다음 시즌 준비 화면에서 데이터 기준 연도를 선택합니다. 목록에는 연도만 표시합니다.
- 게임 속 시즌 연도와 데이터 연도는 독립입니다. 일정은 2026 상대별 경기 수와 날짜 범위를 유지하며 개막·최종 구간을 포함한 연전 묶음을 무작위 재배치합니다. 실제 요일·이동 휴식 배치는 달라지며 진행 중인 세이브 일정은 그대로입니다.
- 현재 제공된 데이터 연도는 2008, 2009, 2010, 2011, 2018, 2019, 2021, 2022, 2023, 2024, 2025입니다. 다른 연도의 선수 데이터가 자동 생성되지는 않습니다.
- 새 파일을 배포 사이트에 넣으려면 다시 빌드한 dist를 업로드합니다.
- 사이트의 시즌 JSON 추가 버튼으로 여러 파일을 가져오면 빌드 없이 이 기기·브라우저의 목록에 저장됩니다. 선택 데이터는 세이브에도 포함됩니다.
- 파일명 연도와 내부 sourceSeason이 다르면 실행용 데이터는 파일명 연도로 보완합니다. 원본 JSON 파일과 선수 성적은 변경하지 않습니다.
