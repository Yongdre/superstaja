# 연도별 리그 데이터

완전한 리그 데이터 JSON을 이 폴더에 둡니다. `kbo-league-data-YYYY.json` 형식을 권장하지만 `2017-season-data.json` 등 다른 파일명도 자동 등록됩니다.

- 파일을 추가한 뒤 개발 서버를 다시 시작합니다.
- 파일명의 첫 4자리 연도로 등록합니다. ver/version 표기는 선택 목록에서 숨깁니다. 파일명에 연도가 없을 때만 JSON의 sourceSeason을 사용합니다.
- 앱은 이 폴더의 파일을 자동 등록합니다.
- 새 커리어와 다음 시즌 준비 화면의 `데이터 기준 연도` 목록에서 직접 고릅니다. 커리어 연도와 데이터 연도는 독립입니다.
- 폴더의 파일을 배포 사이트에 포함하려면 다시 빌드하고 dist를 올립니다.
- 사이트에서 `시즌 JSON 추가`로 여러 파일을 가져오면 빌드 없이 이 브라우저의 목록에 저장됩니다. 선택한 데이터는 세이브에도 포함됩니다.
- 자세한 필드 설명은 프로젝트 루트의 `DATA_GUIDE.md`를 참고하세요.
