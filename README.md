# 슈퍼스타자 & Best Pitcher

타자와 선발투수의 경기 결과를 직접 선택하는 React + TypeScript 웹앱입니다. 첫 화면(`/`)에서 **슈퍼스타자**와 **Best Pitcher**를 선택합니다. 두 게임 모두 안에서 KBO·MLB 리그를 고를 수 있습니다.

태블릿 Codex 클라우드에서 이어서 개발하는 방법과 설치·미리보기 명령은 [클라우드 개발 안내](docs/cloud-development.md)를 참고하세요.

## 슈퍼스타자 · KBO & MLB 타자 커리어

`/superstaja/`에서 KBO·MLB를 선택합니다. 리그마다 기존 선수 데이터·경기 규칙·커리어·자동 저장을 유지하며, 리그 전환은 시작 화면에서 할 수 있습니다. `/superstaja/?league=MLB`로 MLB를 바로 열 수도 있습니다. 데뷔 연도부터 매 시즌을 이어가며 마지막 시즌을 직접 정할 수 있습니다.

## Best Pitcher · 선발투수 커리어

개발 서버의 `/best-pitcher/`에서 실행합니다. 첫 화면의 **Best Pitcher** 카드로도 이동할 수 있습니다. 하나의 게임에서 KBO·MLB를 선택하며, 타자 게임과 저장 공간을 별도로 사용합니다.

- 기존 시즌 폴더의 선수 데이터 선택, 소속 팀·데뷔 연도·좌우완·첫 등판 순번 설정. 초기 화면에서는 선택한 리그·시즌만 불러오고, 읽은 시즌은 재사용해 모바일 첫 진입 부담을 줄입니다.
- 목표는 시즌 최저 방어율 하나입니다. **목표 방어율 이상을 기록하세요.** 시즌 100이닝 초과 후 실제 방어율이 목표보다 0.50 이상 낮으면 3타석 연속 HR만 선택할 수 있습니다. 도중에 방어율이 올라가도 3번을 마쳐야 하며, 끝내기로 경기가 끝나면 남은 횟수는 다음 등판에 이어집니다. 3번을 마친 경기에서는 다시 발동하지 않고, 다음 등판에서 조건을 다시 확인합니다.
- `OUT / 1B / 2B / 3B / HR / BB / IBB / HBP / K / SH / SB / WP / CS·PO` 13개 결과
- OUT은 삼진을 제외한 범타·병살·주자 진루로 처리하며, 삼진은 K로 선택합니다. 문자중계에는 범타 종류를 표시합니다.
- 도루는 성공 결과를 직접 선택하며, 폭투는 모든 주자가 한 베이스씩 진루합니다. 두 이벤트는 상대 타자를 바꾸지 않습니다. 주자가 없거나 진루할 베이스가 막혀 있으면 선택할 수 없습니다.
- 희생번트는 0·1사에 1·2루 주자가 있고 3루가 비어 있을 때 선택할 수 있습니다.
- 도루실패 or 견제사는 가장 앞선 주자 한 명을 아웃 처리합니다. 상대 타자는 그대로이며, 세 번째 아웃이면 이닝을 끝냅니다.
- 등판 종료 후 3·4·5경기 후 등판을 선택합니다. 팀 경기 번호 기준으로 MATCH 1에서 3경기 후를 선택하면 MATCH 4에 등판합니다. 과거 일정에는 실제 등판, 미래 일정에는 현재 간격으로 예상한 등판을 표시합니다.
- KBO 144경기·MLB 162경기 정규시즌, 팀 순위, 문자중계, 시즌·통산 기록, 다음 시즌 진행
- 공격과 다른 경기, 교체 후 불펜은 확률로 자동 진행합니다. 선발투수는 **불펜에 마운드 넘기기**로 교체하며, 투구 수가 선택을 강제로 제한하지 않습니다.
- 승리투수는 최소 5이닝 조건과 유지된 리드를 반영하며, 교체 후 남긴 주자의 실점·자책도 선발 기록에 귀속합니다.
- KBO는 12회까지 진행 후 무승부, MLB는 10회부터 2루 자동 주자를 놓습니다. 자동 주자의 득점은 비자책입니다. 포스트시즌은 이번 버전에 포함하지 않습니다.
- 기록 항목은 등판 수·승–패·방어율·실점·자책·볼넷(고의사구, 사구)·삼진·K/9·QS·QS+·완투·완봉·노히트노런·퍼펙트게임입니다. 볼넷은 사사구 전체 합계이며, K/9는 삼진 × 27 / 아웃 수입니다.
- 리그 선발투수의 실제 자동 경기 기록을 누적해 방어율·승리·삼진·K/9·QS·QS+ 순위를 제공합니다. 선택한 기록 한 열만 표시하고 내 순위와 기록을 맨 위에 보여줍니다. 공동 순위와 규정이닝 필터를 지원하며, 내 선수가 규정이닝 미달이면 전체 선수 기준 순위를 함께 표시합니다. 규정이닝은 집계 기간의 소속 팀 경기 수 × 1이닝입니다. 기존 세이브의 다른 투수 기록은 업데이트 이후 완료된 경기부터 수집합니다.
- 슈퍼스타자와 같은 위에서 아래로 이어지는 문자중계, 출루·득점 강조색, 득점 수와 득점 선수, 실점 화면 알림
- 퍼펙트게임·노히트노런·완봉승·QS·QS+ 조건 달성 화면 알림과 배지. QS는 6이닝 이상 3실점 이하, QS+는 7이닝 이상 3실점 이하로 총 실점을 사용합니다. QS 배지는 현재 조건을 반영하며, 무안타·완봉 알림은 경기 종료 때 판정합니다.
- 현재 연속 삼진 타자와 연속 아웃 타자 표시. 이닝을 넘어 유지하며, 도루·폭투·도루실패·견제사는 타석을 끝내지 않아 연속 타자 기록에 영향을 주지 않습니다. 병살은 아웃 타자 한 명으로 셉니다.
- 브라우저 자동 저장은 투구 기록 숫자를 압축해 MLB 전체 시즌도 저장 용량에 맞춥니다. 내보내기 JSON은 읽기 쉬운 기록 객체를 유지합니다. 기존 저장을 자동 변환하며, 현재 시즌의 QS·QS+·노히트노런은 경기별 기록에서 복원합니다. 복원할 경기별 기록이 없는 과거 시즌의 해당 항목은 —로 표시합니다.

`pnpm build`는 첫 화면, 통합 슈퍼스타자, Best Pitcher를 함께 `dist/`에 빌드합니다. `dist/superstaja/index.html`과 `dist/best-pitcher/index.html`이 각 게임의 진입점입니다. MLB 선수 자료와 일정은 `_mlb/src/data/`에서 읽습니다.

## 기존 게임 실행 안내

최근 엔진 개선과 저장 호환성·시즌 검증 방법은 [시뮬레이션 개선 안내](docs/simulation-improvements.md)를 참고하세요.

Node.js 24와 pnpm이 필요합니다. pnpm이 없다면 Node.js 설치 후 `npm install -g pnpm`으로 설치하세요.

이 저장소를 내려받은 뒤 프로젝트 폴더에서 실행합니다.

```bash
pnpm install --frozen-lockfile
pnpm dev
```

프로덕션 빌드와 테스트:

```bash
pnpm build
pnpm test
```

개발 서버가 표시하는 로컬 주소를 브라우저에서 여세요. 빌드 결과인 `dist` 폴더는 Cloudflare Pages 같은 정적 호스팅에 올릴 수 있습니다. 별도 백엔드나 API 키는 필요하지 않습니다. `node_modules`와 `dist`는 Git에 포함하지 않으며 설치/빌드로 생성합니다.

## 시즌 데이터 선택

`src/data/seasons/`에 넣은 모든 리그 JSON을 자동 등록합니다. 현재 KBO는 2017–2025년 데이터가 포함되어 있습니다.

메인 화면 **새 시즌 시작 → 데이터 기준 연도**에서 연도를 선택하세요. 다음 시즌 준비 화면에서도 사용할 데이터 연도를 직접 고를 수 있습니다.

파일명의 첫 4자리 연도를 사용하고 ver/version 표기는 목록에서 숨깁니다. 게임 속 커리어 연도와 선수 데이터 기준 연도는 독립입니다. 기존 파일명을 교체해도 특정 옛 기본 파일을 요구하지 않습니다.

선수·성적 JSON 원본은 자동 수정하지 않습니다. 프로젝트 폴더의 파일을 배포 사이트에 포함하려면 빌드한 dist를 다시 업로드하세요.

새 커리어는 Seed를 자동 생성하며 같은 시즌·Seed를 직접 지정하면 같은 일정을 재현합니다. KBO는 2·3연전 순서를 무작위로 섞되 상대별 16경기(홈/원정 각각 8경기)를 유지합니다. 다음 시즌도 새 순서로 편성하며 진행 중인 세이브의 일정은 변경하지 않습니다.

리그 JSON만 수정해 가져올 때는 재빌드가 필요 없습니다. 이미 시작한 시즌에는 데이터가 세이브 안에 포함되므로, 파일을 바꾸거나 사이트를 새로고침해도 기존 시즌은 자동 변경되지 않습니다. 새 커리어나 다음 시즌 설정에서 적용하세요.

저장 파일에는 개인 플레이 기록이 들어갑니다. 기기 간 이동은 게임의 **세이브 JSON 내보내기/가져오기**로 하고, 공개 저장소에 개인 세이브를 올리지 마세요.

## 현재 MVP 범위

- `NO HIT / 1B / 2B / 3B / HR / BB / HBP / IBB` 사용자 타석 선택
- 결과 선택 후 해당 결과를 중계창 첫 줄로 고정해 후속 자동 진행 내용을 연속해서 읽는 중계 UX
- NO HIT의 삼진, 땅볼, 뜬공, 라인드라이브, 병살, 희생플라이, 야수선택, 실책 출루 처리
- 안타 뒤 기존 주자의 진루와 홈 보살, 사용자 도루 선택
- 타순, 이닝, 정규시즌 연장 12회·포스트시즌 15회, 투수 교체와 불펜, 경기 종료
- 10팀 × 144경기, 상대별 16경기와 홈/원정 8:8 일정
- 같은 경기일의 다른 4경기와 전체 선수 기록 자동 시뮬레이션
- KBO 승률 방식 순위표, 규정타석 적용 개인 리더보드
- localStorage 자동 저장, 수동 백업 슬롯 3개, JSON 내보내기/가져오기
- 데뷔 연도와 수비 포지션 설정, 매 시즌 시작 전 타순·목표 타율·홈런 한도 설정
- 매 시즌 시작 전 `이번 시즌 후 은퇴` 선택
- 시즌별 이력과 통산 타격 기록 누적, 선택한 마지막 시즌 종료 후 은퇴 처리
- 실제 끝내기 결과와 팀 승리를 순서대로 표시합니다. 기존 타점·득점·홈런·사이클링 히트 알림과 함께 재생됩니다.
- 정규시즌 50안타·10홈런·10도루마다, 통산 1,000안타·100홈런마다 달성 알림을 2초씩 표시합니다. 통산 달성 이력은 기록 화면과 세이브에 보존하며 KBO는 연도·차전·이닝·상대 팀을 남깁니다. 이전 세이브에서 이미 지난 기준의 달성 시점은 복원하지 않습니다.
- KBO 계단식 포스트시즌, 별도 타격 기록, 1–4선발 운용과 5선발 불펜 전환
- 포스트시즌 선발 순서는 팀별 누적 경기 수로 다음 시리즈까지 이어집니다. 플레이오프 3경기를 치르면 한국시리즈는 4선발부터, 직행 팀은 1선발부터 시작합니다. 무승부도 등판 순서에 포함합니다.
- 한 경기에서 이미 등판한 투수는 다시 등판하지 않습니다. 미등판 불펜이 없으면 현재 투수가 계속 던집니다. 이전 세이브는 중계에서 등판 이력을 복원하며, 중계가 잘려 복원이 불가능한 경기에서는 불확실한 불펜의 재등판을 막습니다.
- 다음 시즌 시작 전 도루 성공률(25–95%)을 변경할 수 있습니다. 기본값은 직전 시즌 설정이며, 투수·포수·주루 보정 없이 매 시도 독립적으로 판정합니다.
- 사용자 리그 데이터 JSON 내보내기·검증·가져오기
- 예상 성적 기반 자동 능력치 추정, 멀티 포지션, 부상·백업 출장 배분
- RNG seed 기반 재현성과 `schemaVersion: 4`
- 기존 `schemaVersion: 1/2` 세이브 자동 마이그레이션

## 구조

- `src/engine`: React와 분리된 경기·시즌 엔진, 성적 추정기와 라인업 계획기
- `src/data/seasons/kbo-league-data-YYYY.json`: 연도별 팀·타자·투수 데이터
- `src/data/simulationConfig.ts`: 공통 경기 진행 확률 설정
- `src/store`: 브라우저 저장/JSON 입출력
- `src/components`: 경기, 중계, 순위, 기록 UI
- `src/engine/__tests__`: 통계·야구 규칙·일정·저장·재현성 테스트

## 데이터 메모

기본 내장 `kbo-league-data-2017.json`은 MVP 근사 데이터입니다. 별도의 `2017-season-data.json`은 공식 기록을 출발점으로 사용자 지정 팀 체급을 반영한 조정판이며, 두 파일 모두 실제 최종 성적을 강제하지 않습니다. 다음 연도의 내장 JSON이 없으면 직전 시즌 데이터셋을 유지합니다.

가상의 2099 리그를 만들려면 `src/data/seasons/kbo-league-data-2017.json`을 복사해 `kbo-league-data-2099.json`으로 만들고 내용을 수정하거나, 새 시즌 설정에서 기본 JSON을 내려받아 다시 가져오면 됩니다. 앱은 `src/data/seasons`의 연도별 파일을 자동 등록하며, 시즌 종료 뒤 다음 시즌 설정 화면에서 다음 연도 JSON으로 교체할 수도 있습니다. 자세한 필드와 능력치 기준은 [DATA_GUIDE.md](./DATA_GUIDE.md)를 참고하세요.

빈 입력용 리그 파일은 `src/data/templates/kbo-league-data-template.json`에 있습니다. 10개 팀마다 타자 9명과 투수 10명이 있고, 타자는 예상 성적, 투수는 0–100 능력치 예시가 들어 있습니다. 메인 메뉴의 `성적 입력 템플릿` 버튼으로도 내려받을 수 있습니다.

팀 체급 검증은 `node scripts/audit-team-balance.mjs src/data/seasons/2017-season-data.json 100 5000`으로 재실행할 수 있습니다. 사용자 선수 없이 실제 엔진으로 100개의 정규시즌을 자동 진행하며, 게임 소스나 세이브 파일을 수정하지 않습니다.
